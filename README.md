# Global Superstore Sales Analytics

## Project Overview

This project presents an end-to-end data science solution using the Global Superstore dataset. The objective is to analyze retail sales performance, identify business opportunities, and develop a machine learning model to predict transaction profit.

---

## Project Objectives

- Analyze sales performance
- Study customer behavior
- Evaluate product profitability
- Perform statistical analysis
- Build machine learning models
- Generate business recommendations
- Create interactive dashboards

---

## Technologies Used

- Python

- Power BI
- Jupyter Notebook
